# Noiz AI 使用指南 - PPT 大纲

## Slide 1: 什么是 Noiz AI？

- 文字转语音（TTS）工具
- 支持中文、英文等多语言
- 4 种推荐音色可选
- 应用场景：语音生成、视频配音、无障碍阅读

## Slide 2: 快速开始

1. 获取 API Key（官网注册）
2. Base64 编码 Key
3. curl 调用 API
4. 转换为 MP3（ffmpeg）
