## Unit 7: Days of the Week（星期）

### 核心词汇
| 单词 | 中文 |
|------|------|
| Monday | 星期一 |
| Tuesday | 星期二 |
| Wednesday | 星期三 |
| Thursday | 星期四 |
| Friday | 星期五 |
| Saturday | 星期六 |
| Sunday | 星期日 |
| today | 今天 |
| tomorrow | 明天 |
| diary | 日记 |

### 核心句型
- **What day is it today?** — 今天星期几？
- **It's Monday.** — 今天星期一。
- **What do you do on Monday?** — 你星期一做什么？
- **I go to school on Monday.** — 我星期一上学。
- **We don't go to school on Saturday and Sunday.** — 我们周六周日不上学。

### 频率副词
- always（总是）、often（经常）、sometimes（有时）、never（从不）

## Unit 8: Time（时间）

### 核心词汇
| 单词 | 中文 |
|------|------|
| o'clock | ……点钟 |
| time | 时间 |
| watch | 手表；观看 |
| early | 早 |
| late | 晚、迟 |
| hurry | 赶快 |

### 核心句型
- **What time is it?** — 几点了？
- **It's three o'clock.** — 三点了。
- **It's time to visit Uncle Booky.** — 该去看望 Booky 叔叔了。
- **Excuse me, what time is it?** — 打扰一下，几点了？

### 时间表达
- 整点：three o'clock（三点）
- 非整点：one fifteen（一点十五）、one forty-five（一点四十五）

## Unit 9: Day and Night（白天与夜晚）

### 核心词汇
| 单词 | 中文 |
|------|------|
| morning | 早晨 |
| afternoon | 下午 |
| evening | 傍晚 |
| night | 夜晚 |
| breakfast | 早餐 |
| lunch | 午餐 |
| get up | 起床 |
| go to bed | 上床睡觉 |
| go to school | 去上学 |
| exercise | 锻炼 |

### 核心句型
- **When do you get up?** — 你什么时候起床？
- **I always get up at five in the morning.** — 我总是早上五点起床。
- **I often go to bed at ten.** — 我经常十点上床睡觉。
- **I never sleep in class!** — 我从不课上睡觉！

### 语法要点
- 频率副词位置：在动词前（I **always** get up at five.）
- 时间介词：in the morning/afternoon/evening，at night，at + 时间点

## Unit 10: Activities（活动）

### 核心词汇
| 单词 | 中文 |
|------|------|
| activity | 活动 |
| museum | 博物馆 |
| film | 电影 |
| dinosaur | 恐龙 |
| library | 图书馆 |
| homework | 作业 |
| group | 小组 |
| enough | 足够的 |
| free | 免费的 |

### 核心句型
- **Shall we watch a film?** — 我们看电影好吗？
- **Let's go to the science museum.** — 我们去科学博物馆吧。
- **Is there a film about dinosaurs?** — 有关于恐龙的电影吗？
- **It's too expensive.** — 太贵了。
- **That's a good idea.** — 好主意。

### 交通方式
- by bus（乘公交）、by taxi（乘出租车）、by car（乘汽车）、on foot（步行）

## Unit 11: Weather（天气）

### 核心词汇
| 单词 | 中文 |
|------|------|
| sunny | 晴朗的 |
| cloudy | 多云的 |
| rainy | 下雨的 |
| windy | 有风的 |
| snowy | 下雪的 |
| weather | 天气 |

### 核心句型
- **What's the weather like today?** — 今天天气怎么样？
- **It's sunny today.** — 今天是晴天。
- **It's going to be cloudy tomorrow.** — 明天会是多云。
- **What are we going to do?** — 我们要做什么？
- **We are going to ride the horses.** — 我们要去骑马。

### 语法要点
- be going to 结构：表示将来计划或预测
- It's going to be + 形容词（天气预测）

## 学习建议

1. **词汇记忆**：结合图片和情境记忆，不要死记硬背
2. **句型练习**：多用替换练习，把单词放进句子里
3. **听力训练**：多听课文录音，模仿语音语调
4. **口语表达**：大胆说，不怕犯错
